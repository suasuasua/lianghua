# 板块轮动量化交易工具

一个基于 A 股行业 ETF 的板块轮动量化分析与自动可视化工具。

## 这个工具做什么？

### 核心理念

你提出的想法：**市场上的资金在板块之间流动**——当资金从某些板块撤出时，往往会流入其他板块。

这个工具用三种量化方法来验证和利用这一规律：

| 方法 | 通俗解释 | 输出 |
|------|---------|------|
| **Granger 因果检验** | 板块A的历史涨跌能否预测板块B的未来涨跌？ | 因果关系图 |
| **VAR 向量自回归** | 根据多个板块的历史数据，联合预测未来走势 | 预测排名 |
| **协整检验** | 两个板块是否存在长期均衡关系？价差大了会不会回归？ | 配对交易信号 |
| **综合评分** | 动量(40%) + 轮动预测(35%) + 相对强度(25%) | 买入/卖出信号 |

## 运行流程

### 本地运行

```bash
# 1. 下载数据（24个行业ETF，近300个交易日）
python main.py --days 300 fetch

# 2. 分析板块关系（相关性 + Granger因果）
python main.py --data sector_data.csv analyze

# 3. 生成交易信号（买入/持有/卖出）
python main.py --data sector_data.csv signal

# 4. 回测策略
python main.py --data sector_data.csv --capital 100000 backtest

# 5. 一键全流程
python main.py --days 300 run
```

## 仪表盘里有什么？

| 模块 | 说明 |
|------|------|
| **今日交易信号** | 23个板块的综合评分排名，标记买入/持有/卖出 |
| **回测表现** | 近15个月的模拟交易结果（收益率、最大回撤、夏普比率） |
| **板块相关性矩阵** | 热力图，鼠标悬停看任意两个板块的相关系数 |
| **Granger 因果关系** | 力导向图，箭头方向表示"原因→结果"，线越粗越显著 |
| **板块走势对比** | 所有板块归一化到100起点的走势叠加图 |
| **协整配对** | 存在长期均衡关系的板块对（价差偏离过大时可做配对交易） |
| **配对交易信号** | 当前协整对的z-score和交易建议 |

## 常见问题

**Q: 数据从哪里来？**
腾讯财经公开 API（web.ifzq.gtimg.cn），不需要 API Key。

**Q: 每天什么时候更新？**
北京时间工作日 00:30（A股收盘后）自动更新数据并重新生成报告。

**Q: 这个策略能赚钱吗？**
仅供参考研究。回测表现（+29%）不代表未来收益，市场风格变化可能让策略失效。

**Q: 我想换一批板块怎么改？**
编辑 `config.py` 里的 `SECTOR_ETFS` 字典，添加或删除板块代码即可。

**Q: 我想修改策略参数？**
编辑 `config.py` 里的 `StrategyConfig` 类：
- `top_n_buy` = 每次买入几个板块
- `bottom_n_sell` = 每次卖出几个板块
- `lookback_days` = 回看多少天数据
- `granger_alpha` = Granger检验的显著性水平
